# Ticket - Project
เป็นเว็บไซต์การแจ้งปัญหาการใช้งานของฝ่าย IT 

ด้วยความที่ในปีแรกที่ได้เริ่มทำงานอย่างจริงจังได้เข้าไปทำงานในสาย PHP และทางบริษัทกำลังจะพัฒนาระบบไปใช้ภาษา Java
