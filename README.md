# Ticket Project

โปรเจกต์นี้คือระบบแจ้งปัญหาการใช้งานสำหรับฝ่าย IT พัฒนาด้วย Java และ Spring Boot โดยผู้ใช้สามารถสมัครสมาชิก, ล็อกอิน, แจ้งปัญหา, แนบรูปภาพ, และติดตามสถานะงานได้ ส่วนผู้ดูแลระบบสามารถจัดการรายการแจ้งปัญหา, จัดการผู้ใช้, ดูสรุปบน Dashboard และส่งออกข้อมูลเป็นไฟล์ Excel ได้

## เทคโนโลยีที่ใช้

- `Java 17`
- `Spring Boot 3.3.3`
- `Spring Web` สำหรับทำเว็บแอปแบบ MVC
- `Spring Data JPA` สำหรับเชื่อมต่อและจัดการฐานข้อมูล
- `Spring Security` สำหรับระบบล็อกอินและกำหนดสิทธิ์ผู้ใช้
- `Thymeleaf` สำหรับแสดงผลหน้าเว็บฝั่ง Server
- `MariaDB` สำหรับฐานข้อมูลหลัก
- `Apache POI` สำหรับ Export ข้อมูลออกเป็นไฟล์ Excel
- `Maven` สำหรับจัดการ dependency และ build project
- `HTML / CSS / JavaScript` สำหรับหน้าบ้าน

## ความสามารถหลักของระบบ

### ฝั่งผู้ใช้งาน
- สมัครสมาชิกและเข้าสู่ระบบ
- แก้ไขข้อมูลโปรไฟล์
- แจ้งปัญหาการใช้งานผ่านฟอร์ม
- แนบรูปภาพประกอบปัญหาได้
- ดูประวัติการแจ้งปัญหาของตัวเอง
- ยกเลิกรายการแจ้งปัญหาได้ในบางสถานะ
- ดูหน้าสรุปสถานะงานและหน้าเนื้อหาเพิ่มเติม เช่น `Guide`, `FAQ`, `Use AI in Work`

### ฝั่งผู้ดูแลระบบ
- เข้าหน้า `Dashboard` เพื่อดูจำนวนงานตามสถานะ
- ดูรายการปัญหาทั้งหมด
- เปลี่ยนสถานะงานแจ้งปัญหา
- เพิ่มผู้ใช้งานจากหลังบ้าน
- ดูรายชื่อผู้ใช้ทั้งหมด
- แก้ไขข้อมูลผู้ใช้
- Export รายการปัญหาเป็น Excel
- Export รายชื่อผู้ใช้เป็น Excel

## การกำหนดสิทธิ์ผู้ใช้

ระบบใช้ `Spring Security` แยกสิทธิ์หลักออกเป็น 2 ระดับ

- `Admin` เข้าถึงหน้า dashboard, จัดการผู้ใช้, จัดการปัญหา, และ export ข้อมูล
- `User` เข้าถึงหน้าหลัก, แจ้งปัญหา, ดูประวัติรายการของตัวเอง, และแก้ไขโปรไฟล์

รหัสผ่านถูกเข้ารหัสด้วย `BCrypt` ก่อนบันทึกลงฐานข้อมูล

## โครงสร้างการทำงานของโปรเจกต์

โปรเจกต์นี้เป็นรูปแบบ `Spring MVC`

- `controller` รับ request จากหน้าเว็บและจัดการ flow ของระบบ
- `service` รวม business logic เช่น สมัครสมาชิก, export excel, อัปเดตสถานะ
- `repository` ติดต่อฐานข้อมูลผ่าน JPA
- `entity` เป็น model ที่ mapping กับตารางในฐานข้อมูล
- `templates` เป็นหน้าเว็บ `Thymeleaf`
- `static` เก็บไฟล์ `CSS`, `JavaScript`, และรูปภาพ
- `uploads` ใช้เก็บไฟล์รูปที่ผู้ใช้แนบตอนแจ้งปัญหา

มีไฟล์ SQL ตัวอย่างอยู่ในโฟลเดอร์ [`filedb`](./filedb) สำหรับใช้ประกอบการสร้างฐานข้อมูล
